## Exercice 1 — Réseau de neurones from scratch (PyTorch + NumPy + Pandas + Matplotlib)

**Dataset** : [Give Me Some Credit](https://www.kaggle.com/datasets/brycecf/give-me-some-credit-dataset)

**Consigne** : Charger et prétraiter avec Pandas (imputation médiane groupée, suppression outliers IQR). Normaliser avec scikit-learn `RobustScaler`. Convertir en tenseurs PyTorch avec `torch.tensor`. Implémenter un MLP from scratch sans utiliser `nn.Sequential` : créer une classe héritant de `nn.Module` avec 4 couches denses, BatchNorm, Dropout(0.3) et activation GELU. Implémenter un scheduler `CosineAnnealingLR`. Gérer le déséquilibre des classes avec `pos_weight` dans `BCEWithLogitsLoss` (calculer le ratio avec NumPy). Tracer avec Matplotlib les courbes de perte train/val, le taux d'apprentissage par epoch, et la courbe ROC finale comparée au meilleur modèle scikit-learn de l'exercice 9.

**Concepts attendus** : `nn.Module`, `BCEWithLogitsLoss(pos_weight)`, `CosineAnnealingLR`, `BatchNorm1d`, `Dropout`, `DataLoader`, courbe ROC

## Exercice 2 — CNN pour classification d'images médicales (PyTorch + OpenCV + NumPy + Matplotlib)

**Dataset** : [Chest X-Ray Images (Pneumonia)](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia)

**Consigne** : Charger les radiographies avec OpenCV. Appliquer le pipeline de prétraitement de l'exercice 6 sklearn (CLAHE, resize 224×224). Construire un `Dataset` PyTorch custom avec augmentation de données : flip horizontal, rotation aléatoire (±15°) et ajout de bruit gaussien, tous implémentés avec NumPy (sans torchvision). Implémenter un CNN avec 5 blocs convolutifs (Conv2d → BatchNorm → ReLU → MaxPool), Global Average Pooling et une tête de classification. Visualiser avec Matplotlib les feature maps de la première et dernière couche convolutive pour 3 images. Comparer les métriques (F1, AUC) avec le `RandomForestClassifier` de l'exercice 6 sklearn dans un DataFrame Pandas.

**Concepts attendus** : `Dataset` custom, `DataLoader`, `Conv2d`, `BatchNorm2d`, GAP, augmentation NumPy, feature maps Matplotlib

## Exercice 3 — Transfer Learning et fine-tuning (PyTorch + OpenCV + Pandas + Matplotlib + scikit-learn)

**Dataset** : [Intel Image Classification](https://www.kaggle.com/datasets/puneet6060/intel-image-classification)

**Consigne** : Charger les images avec OpenCV et construire un `Dataset` custom. Charger un ResNet-18 pré-entraîné avec `torchvision.models`. Geler tous les paramètres sauf les 2 derniers blocs résiduels et la tête. Remplacer la tête par un classifieur custom (Dropout + Linear + GELU + Linear). Entraîner avec `AdamW` et `OneCycleLR`. Extraire les embeddings de la couche avant la tête avec un hook PyTorch (`register_forward_hook`). Projeter les embeddings avec `TSNE` de scikit-learn et afficher avec Matplotlib. Comparer les embeddings avant et après fine-tuning côte à côte. Calculer la matrice de confusion avec scikit-learn et l'afficher avec Matplotlib.

**Concepts attendus** : `register_forward_hook`, `OneCycleLR`, `AdamW`, freeze de paramètres, embeddings, `TSNE`, hook PyTorch

Implémenter un LSTM multi-couches avec `nn.LSTM` (2 couches, hidden_size=128) suivi d'une couche d'attention simple (produit scalaire) et d'une tête de régression. Afficher avec Matplotlib les prédictions vs réalité pour 3 magasins et la distribution des erreurs.

**Concepts attendus** : `nn.LSTM`, attention scalaire, fenêtres glissantes `Dataset`, `TimeSeriesSplit`, MAPE NumPy, `pack_padded_sequence`

## Exercice 5 — Autoencodeur variationnel (VAE) pour détection d'anomalies (PyTorch + Pandas + NumPy + Matplotlib)

**Dataset** : [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

**Consigne** : Charger avec Pandas. Entraîner le VAE uniquement sur les transactions normales. Implémenter le VAE avec `nn.Module` : encodeur (4 couches Linear + LeakyReLU) → vecteurs `mu` et `log_var` → reparameterization trick avec NumPy/PyTorch → décodeur symétrique. Implémenter la loss ELBO (reconstruction BCE + KL divergence) avec pondération β (β-VAE). Utiliser l'erreur de reconstruction comme score d'anomalie sur le test set. Comparer avec `IsolationForest` et `LocalOutlierFactor` de l'exercice 2 sklearn dans un DataFrame Pandas. Visualiser avec Matplotlib l'espace latent 2D (si dim=2) coloré par classe et la distribution des erreurs de reconstruction.

**Concepts attendus** : reparameterization trick, ELBO loss, β-VAE, espace latent, comparaison avec sklearn anomaly detectors

Évaluer la qualité des images générées avec le Fréchet Inception Distance (FID) simplifié (distance entre distributions de features extraites avec PCA sklearn). Les features des nœuds clients sont les vecteurs RFM de l'exercice 4 sklearn. Prédire la propension au ré-achat (classification binaire). ## Exercice 10 — Pipeline MLOps complet (PyTorch + toutes les libs)

**Dataset** : [House Prices](https://www.kaggle.com/datasets/lespin/house-prices-dataset) + [Intel Image Classification](https://www.kaggle.com/datasets/puneet6060/intel-image-classification) + [Amazon Reviews](https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews)

**Consigne** : Construire un pipeline bout-en-bout qui intègre **tous les exercices précédents**. (1) **Ingestion** : charger les 3 datasets avec Pandas, détecter et corriger les anomalies avec `IsolationForest` sklearn. (2) **Features** : features tabulaires (RobustScaler sklearn + NumPy), features images (OpenCV CLAHE + CNN embeddings de l'exercice 3), features texte (TF-IDF sklearn + Transformer embeddings de l'exercice 6). (3) **Fusion** : concaténer les 3 types de features dans un MLP PyTorch multimodal avec des têtes spécialisées par modalité et une couche de fusion finale. (4) **Validation** : cross-validation `StratifiedKFold` sklearn, bootstrap IC NumPy, calibration des probabilités. (5) **Analyse des erreurs** : identifier les cas d'échec avec Pandas, afficher avec Matplotlib un dashboard complet (courbes d'apprentissage, matrice de confusion, distribution des erreurs par modalité, importance des features par tête).

**Concepts attendus** : pipeline multimodal, têtes spécialisées, fusion tardive, bootstrap NumPy, `StratifiedKFold`, dashboard Matplotlib, toutes les libs combinées
