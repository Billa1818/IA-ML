## Exercice 1 — Fine-tuning BERT pour classification de sentiments (Transformers + Pandas + NumPy + Matplotlib + scikit-learn)

**Dataset** : [Amazon Fine Food Reviews](https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews)

**Consigne** : Charger et nettoyer avec Pandas (str accessors de l'exo 12 sklearn). Tokeniser avec `BertTokenizerFast` en batch, gérer le padding et truncation à 256 tokens. Construire un `Dataset` PyTorch custom retournant `input_ids`, `attention_mask` et `labels`. Fine-tuner `BertForSequenceClassification` (5 classes) avec `AdamW` + `get_linear_schedule_with_warmup`. Comparer les embeddings [CLS] extraits avec `BertModel` (hook PyTorch exo 3 torchvision) projetés en TSNE sklearn (exo 7 torchvision) avec les embeddings TF-IDF sklearn (exo 5 sklearn) dans un DataFrame Pandas. Afficher avec Matplotlib : courbes de perte, matrice de confusion, distribution des embeddings [CLS] par classe.

**Concepts attendus** : `BertTokenizerFast`, `BertForSequenceClassification`, `get_linear_schedule_with_warmup`, embeddings [CLS], TSNE sklearn, comparaison TF-IDF

Calculer avec NumPy la distribution de confiance par type d'entité. Construire un graphe de co-occurrence entités avec `cosine_similarity` sklearn (exo 5 sklearn). ## Exercice 10 — Système RAG (Retrieval-Augmented Generation) complet (Transformers + toutes les libs)

**Dataset** : [Wikipedia Medical Articles](https://www.kaggle.com/datasets/towardsdatascience/wikipedia-medical-articles) + [Chest X-Ray](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia) + [Amazon Reviews](https://www.kaggle.com/datasets/snap/amazon-fine-food-reviews)

**Consigne** : Construire un système RAG bout-en-bout qui réutilise **toutes les libs et tous les exercices précédents**. **(1) Indexation** : encoder les articles médicaux avec `SentenceTransformer` (exo 5 Transformers), stocker les embeddings dans un index `NearestNeighbors` sklearn (exo 5 Transformers). **(2) Retrieval multimodal** : pour une requête texte ou image (radiographie OpenCV + DeepLab exo 3 torchvision), récupérer les top-K documents pertinents. **(3) Génération** : concaténer la requête + documents récupérés comme contexte pour `T5ForConditionalGeneration` (exo 4 Transformers). **(4) Évaluation** : calculer ROUGE NumPy (exo 4) + BERTScore (exo 9) + Faithfulness (cosine similarity réponse/contexte). **(5) Dashboard** : rapport Matplotlib complet (exo 8 sklearn) : qualité du retrieval (Recall@K NumPy), distribution des métriques de génération par domaine Pandas, TSNE de l'espace d'embedding, cartes d'attention ViT sur les images médicales.

**Concepts attendus** : RAG pipeline, `SentenceTransformer`, `NearestNeighbors`, T5 génération, BERTScore, ROUGE NumPy, DeepLab torchvision, dashboard Matplotlib, toutes les libs
