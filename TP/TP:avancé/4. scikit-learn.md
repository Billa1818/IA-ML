## Exercice 1 — Pipeline de classification sur images (scikit-learn + OpenCV + NumPy + Matplotlib)

**Dataset** : [Intel Image Classification](https://www.kaggle.com/datasets/puneet6060/intel-image-classification)

**Consigne** : Charger les images avec OpenCV. Extraire des features manuellement avec NumPy : histogramme de couleurs HSV (32 bins par canal), histogramme de gradients orientés (HOG simplifié : magnitude et orientation avec `np.arctan2`), et texture via la matrice de co-occurrence (LBP simplifié). Construire un DataFrame Pandas avec ces features. Construire un `Pipeline` scikit-learn : `StandardScaler` → `PCA(n_components=50)` → `SVC(kernel='rbf')`. Optimiser les hyperparamètres avec `GridSearchCV` (C et gamma). Afficher avec Matplotlib la matrice de confusion, le rapport de classification et les courbes d'apprentissage (`learning_curve`).

**Concepts attendus** : OpenCV HOG, `Pipeline`, `GridSearchCV`, `learning_curve`, `confusion_matrix`, Matplotlib `imshow`

**Dataset** : [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Exercice 3 — Régression avec sélection de features (scikit-learn + Pandas + NumPy + Matplotlib)

**Dataset** : [House Prices — Advanced Regression](https://www.kaggle.com/datasets/lespin/house-prices-dataset)

**Consigne** : Charger avec Pandas. Construire un pipeline de prétraitement avec `ColumnTransformer` : `SimpleImputer` + `StandardScaler` pour les numériques, `SimpleImputer` + `OneHotEncoder` pour les catégorielles. Comparer 4 modèles de régression : `Ridge`, `Lasso`, `ElasticNet`, `GradientBoostingRegressor`. Appliquer `RFE` (Recursive Feature Elimination) avec le meilleur modèle pour sélectionner les 20 features les plus importantes. Avec NumPy, calculer manuellement le RMSE et le R² sur le test set. Visualiser avec Matplotlib : importance des features, résidus vs prédictions, et Q-Q plot des résidus.

**Concepts attendus** : `ColumnTransformer`, `RFE`, `ElasticNet`, `GradientBoostingRegressor`, Q-Q plot NumPy, résidus

## Exercice 10 — Système de recommandation hybride (scikit-learn + Pandas + NumPy + Matplotlib + OpenCV)

**Dataset** : [MovieLens 1M](https://www.kaggle.com/datasets/odedgolden/movielens-1m-dataset) + [Movie Posters](https://www.kaggle.com/datasets/ghrzarea/movielens-20m-posters-for-machine-learning)

**Consigne** : Charger ratings et metadata avec Pandas. Construire deux systèmes de recommandation : (1) **Collaboratif** — matrice utilisateurs × films, SVD tronquée avec `TruncatedSVD` (scikit-learn), prédire les ratings manquants par produit matriciel NumPy. (2) **Contenu** — charger les affiches de films avec OpenCV, extraire un vecteur de features couleur (histogramme HSV) + texte (`TfidfVectorizer` sur les genres/tags), calculer la similarité cosinus avec `cosine_similarity`. Fusionner les deux scores avec une pondération apprise par `Ridge` sur les préférences utilisateur. Évaluer le NDCG@10 implémenté avec NumPy. Afficher avec Matplotlib : heatmap des similarités entre genres, distribution des scores hybrides vs collaboratif seul.

**Concepts attendus** : `TruncatedSVD`, `cosine_similarity`, `TfidfVectorizer`, NDCG NumPy, OpenCV histogramme HSV, fusion hybride `Ridge`

## Concepts scikit-learn couverts

- **Preprocessing** : `StandardScaler`, `RobustScaler`, `OneHotEncoder`, `ColumnTransformer`, `SimpleImputer`
- **Pipelines** : `Pipeline`, `FeatureUnion`, `set_output`
- **Classification** : `SVC`, `RandomForestClassifier`, `LogisticRegression`, `ComplementNB`, `BaggingClassifier`
- **Régression** : `Ridge`, `Lasso`, `ElasticNet`, `GradientBoostingRegressor`, `HistGradientBoostingRegressor`
- **Clustering** : `KMeans`, `AgglomerativeClustering`, `DBSCAN`
- **Détection d'anomalies** : `IsolationForest`, `LocalOutlierFactor`, `EllipticEnvelope`
- **Réduction de dimension** : `PCA`, `TruncatedSVD`, `TSNE`, `Isomap`
- **Sélection de features** : `RFE`, `feature_importances_`, `SelectKBest`
- **Texte** : `TfidfVectorizer`, `HashingVectorizer`
- **Évaluation** : `cross_val_score`, `TimeSeriesSplit`, `GridSearchCV`, `HalvingRandomSearchCV`, `calibration_curve`, `roc_curve`, `silhouette_score`
- **Métriques custom** : NDCG NumPy, MAPE Pandas, stress de Sammon NumPy, bootstrap IC NumPy
