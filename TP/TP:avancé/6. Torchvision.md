## Exercice 1 — Augmentation avancée et visualisation du pipeline (torchvision + OpenCV + NumPy + Matplotlib + Pandas)

**Dataset** : [Intel Image Classification](https://www.kaggle.com/datasets/puneet6060/intel-image-classification)

**Consigne** : Charger les images avec OpenCV (pipeline CLAHE de l'exercice 2 PyTorch). Construire deux pipelines d'augmentation parallèles : (1) **torchvision** avec `transforms.Compose` : `RandomResizedCrop`, `RandomHorizontalFlip`, `ColorJitter`, `GaussianBlur`, `RandomErasing`, normalisation ImageNet. (2) **NumPy/OpenCV** : rotation aléatoire `warpAffine`, bruit gaussien, flip, CLAHE. Comparer les deux pipelines sur 100 images : calculer avec NumPy la distance moyenne entre les distributions de pixels (KL divergence entre histogrammes). Construire un DataFrame Pandas avec les statistiques (mean, std, min, max) de chaque version augmentée. Afficher avec Matplotlib une grille 4×8 comparant visuellement les deux approches. Utiliser `ToPILImage` et `ToTensor` de torchvision pour la conversion.

**Concepts attendus** : `transforms.Compose`, `RandomErasing`, `ColorJitter`, `GaussianBlur`, KL divergence NumPy, grille Matplotlib

## Exercice 2 — Détection d'objets avec Faster R-CNN pré-entraîné (torchvision + OpenCV + Pandas + Matplotlib + NumPy)

**Dataset** : [Fruit Images for Object Detection](https://www.kaggle.com/datasets/mbkinaci/fruit-images-for-object-detection)

**Consigne** : Charger les images avec OpenCV (appliquer la segmentation couleur HSV de l'exercice 2 sklearn comme prétraitement). Charger `fasterrcnn_resnet50_fpn` pré-entraîné avec `torchvision.models.detection`. Passer chaque image en inférence et récupérer les boîtes, labels et scores. Post-traiter avec NumPy : appliquer le NMS (Non-Maximum Suppression) manuellement (IoU = intersection/union calculé vectorisé). Comparer les détections torchvision avec les détections par contours OpenCV de l'exercice 2 sklearn dans un DataFrame Pandas (nombre de détections, IoU moyen). Afficher avec Matplotlib les images annotées côte à côte (torchvision vs OpenCV) avec les scores de confiance.

**Concepts attendus** : `fasterrcnn_resnet50_fpn`, NMS NumPy vectorisé, IoU, `torchvision.ops.nms`, comparaison OpenCV vs DL, Pandas

## Exercice 5 — Génération d'images avec StyleGAN-like simplifié (torchvision + PyTorch + NumPy + Matplotlib + OpenCV)

**Concepts attendus** : `make_grid`, `save_image`, AdaIN, MiniBatch Std, FID PCA sklearn, Haar cascade OpenCV, ProGAN simplifié

## Exercice 6 — Reconnaissance d'actions vidéo (torchvision + PyTorch + OpenCV + Pandas + NumPy + Matplotlib)

Modifier la tête pour la classification binaire (normal/anormal). Fusionner les features RGB et flux optique avec une couche d'attention (exo 4 PyTorch). **Concepts attendus** : `r3d_18`, `torchvision.models.video`, clip Dataset, flux optique OpenCV, attention LSTM PyTorch, `cross_val_score` sklearn

## Exercice 7 — Self-supervised Learning avec SimCLR (torchvision + PyTorch + NumPy + Matplotlib + scikit-learn)

**Dataset** : [Fashion MNIST](https://www.kaggle.com/datasets/zalando-research/fashionmnist)

**Consigne** : Charger avec Pandas et reshaper avec NumPy (exo 8 sklearn). Entraîner un encodeur ResNet-18 (`torchvision.models`) avec la loss NT-Xent (Normalized Temperature-scaled Cross Entropy) implémentée en PyTorch. Évaluer la qualité des représentations apprises avec un classifieur linéaire `LogisticRegression` sklearn entraîné sur les embeddings figés. Projeter les embeddings avec TSNE sklearn et comparer avec les embeddings supervisés de l'exo 2 PyTorch. Afficher avec Matplotlib les paires positives les plus proches et les plus éloignées dans l'espace latent.

**Concepts attendus** : SimCLR, NT-Xent loss, `GaussianBlur` torchvision, évaluation linéaire sklearn, TSNE comparaison, paires positives/négatives

## Exercice 10 — Pipeline de vision industrielle complet (torchvision + toutes les libs)

**Dataset** : [MVTec Anomaly Detection](https://www.kaggle.com/datasets/ipythonx/mvtec-ad) + [KITTI](https://www.kaggle.com/datasets/garymk/kitti-3d-object-detection-dataset) + [LFW](https://www.kaggle.com/datasets/jessicali9530/lfw-dataset)

**Consigne** : Construire un système de vision industrielle bout-en-bout qui réutilise **tous les exercices précédents**. **(1) Détection d'anomalies visuelles** : charger MVTec avec OpenCV (CLAHE exo 6 sklearn), utiliser le VAE de l'exo 5 PyTorch pour détecter les défauts, affiner avec `deeplabv3` (exo 3 torchvision) pour segmenter les zones défectueuses. **(2) Tracking multi-objets** : charger des séquences KITTI, détecter avec `fasterrcnn_resnet50_fpn` (exo 2 torchvision), tracker les objets avec le flux optique OpenCV (exo 3 sklearn) + filtre de Kalman implémenté en NumPy. **(3) Identification de personnes** : charger LFW, extraire des embeddings avec SimCLR (exo 7 torchvision), indexer avec `NearestNeighbors` sklearn (exo 1 sklearn). **(4) Dashboard** : construire avec Matplotlib un rapport complet (exo 8 sklearn) : courbes de précision, cartes de chaleur des anomalies, trajectoires de tracking, galerie d'identification. Toutes les métriques dans un DataFrame Pandas.

**Concepts attendus** : pipeline multi-tâches, `fasterrcnn`, filtre de Kalman NumPy, SimCLR embeddings, `NearestNeighbors` sklearn, VAE anomaly, dashboard Matplotlib, toutes les libs
